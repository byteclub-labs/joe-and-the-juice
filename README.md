# joe-and-the-juice
Joe &amp; The Juice — basic coffee &amp; juice shop single-page app with a 20-item catalogue (built by the Devin software factory)

## Run it

Static frontend only — no build, no dependencies.

- Open `index.html` directly in a browser, or
- Serve the folder: `python3 -m http.server 8000` → http://localhost:8000
